# plan/04 — 数据计划

> 数据台账与纪律见 `data/README.md`（依据查证、数据源三态、合成数据纪律、数值口径唯一定义处）。本文只做执行安排。

## 一、数据形态总览

本题**无外部数据依赖**（输入为用户本地 CSV/TSV；规则与阈值自持；运行时零网络）。数据资产只有一类：**程序化自制的合成数据 + 植入真值**。

## 二、`data/synthetic/` 冻结产物清单

| 产物 | 内容 | 生成者 |
| --- | --- | --- |
| `synthetic_groups.csv` | 多组 / 少样本 / 偏斜 / 多峰 / 均匀组（G2 主战场） | `tools/gen_synthetic.py` |
| `synthetic_errorbars.tsv` | sd / sem / ci / n 四种声明 + 各反例（G3 主战场） | 同上 |
| `spec_*.json` | 每张图的图表规格 | 同上 |
| `truth.json` | 真值台账：`chart_id / expected_verdict / expected_errors[] / expected_provenance[]` | 同上 |
| `manifest.json` | 全部冻结产物 sha256 + 生成器与口径文件 sha256 | 同上 |

生成纪律（题面 + data/README §三）：
- 固定 seed、**禁 stdlib random、禁系统时钟、禁 set 迭代序**（自研确定性 RNG）；
- 真值与 CSV **同源生成，严禁手抄回填**；真值只存输入与期望，无 `observed_*`；
- M1 冻结，此后只读；改生成器 → 重生成整目录 + `--check` 位级一致守门（两层：冻结产物形态断言 + 重生成逐字节比对）；
- 假业务主题白名单（data/README §3.1）配校验脚本，CI 可跑。

## 三、植入真值覆盖矩阵（最低集）

1. 干净图 → `pass`；
2. M3 九类规则各 ≥1 例（级别按 `references/rules.json`）；
3. G1 四形态：缺溯源 / match=false / 行列不存在 / 哈希不符；
4. G2：n<N_MIN+偏斜、n<N_MIN+多峰、n<N_MIN 但均匀（应通过）、合规替代两形态；
5. G3：`sd/sem/ci/n` 四声明 × 正反例，含"仅标题写 SEM 无来源"反例；
6. 溯源正例：指定渲染值命中指定 `(row_index, column)`，`raw_cell` 逐字符相等。

**可检出性下限**（skill 纪律）：G2 植入的偏斜/多峰信号必须对准口径 §7/§8 的判定线（偏度 |g1|>1.0、多峰 bins=6 判据）做**生成期断言**——生成器自行用公式复算并断言"该组判为偏斜/多峰"，防止"植入了个信号但检测器看不见"的假真值；下限数值（g1 实算值、双峰 bin 计数）写进 truth.json 供复核。

## 四、基准落点

- 基准脚本 `tools/bench.py`：真值全量实跑于交付态入口 `chartaudit check/build`；期望值由基准运行时独立复算（与引擎实现相互独立，判别 = "注释掉引擎，真值还能算出来吗"）。M2 已覆盖 parse + provenance（29/29 达标）；M5 扩展全链与 HTML 产物断言。
- 退出码三语义 + 检出率 ≥ 阈值 + 逐样本点名 + 逐类覆盖 `min_required`，锁进 pytest。

## 五、里程碑对齐

| 里程碑 | 数据动作 |
| --- | --- |
| M1 | 生成器 + 合成 CSV/TSV + truth.json + manifest + 白名单校验 + 冻结 |
| M2 | 溯源正例真值启用；独立重算基准 |
| M3 | 九类规则真值启用 |
| M4 | G1/G2/G3 正反例真值启用 |
| M5 | 全链基准绿 + 样例产物（一份通过图 + 一份阻断图 HTML） |

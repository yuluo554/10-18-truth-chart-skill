| **D3** | **本题只押三条窄缝**：①逐值溯源到源单元格 ②n 过小且偏斜 / 多峰时禁止均值柱 ③误差棒 `sd` / `sem` / `ci` / `n` 来源真实性 | 做全量反误导检查器 + 全量溯源 + 全量统计语义（摊大饼） | 窄缝才有差异化；首期 5 模块已足够满 |
| **D4** | **若开发时放弃任一窄缝，本题退化为对已有 checker 的重复实现，应视为失败** | 降级为"通用图表检查 skill"继续交付 | 去掉任一窄缝后，剩余能力与 `artgas1/tufte-skill` / `honest-chart` 高度重合，失去立项理由 |
| D5 | 交付形态收敛为**唯一 Agent Skill + 单文件 HTML** | GUI / 桌面 exe / 在线服务 | 形态留后门会给空壳通行证；本题核心是审计链与确定性渲染 |
| D6 | 自研自有**规格 JSON**，不解析 Vega-Lite / Plotly / ECharts | 做通用 spec 兼容层 | `artgas1/tufte-skill` 已覆盖 spec 检查；通用兼容层是无底洞且偏离溯源主线 |
| D7 | 渲染输出**内联 SVG + 无 JavaScript 依赖**（仅内联少量交互脚本） | ECharts / D3 / Chart.js 等库 | 零 CDN 要求；重型库破坏确定性布局与字节级可复现 |
| D8 | 布局**全固定几何常量**，禁止自适应 / 随机抖动 | 力导向、响应式缩放、jitter | 不可复现的图形无法做字节级断言与真值基准 |
| D9 | 审计比对用 **Fraction 精确有理数** | 直接用二进制浮点比较 | 百分比 / 均值舍入会制造假阳性与假阴性 |
| D10 | 存在 `ERROR` 时**默认不写可发布 HTML** | 先出图再提示"有问题" | 发布门禁的意义在于阻断，"生成成功 + 警告"等于没有门禁 |
| D11 | 样本量 / 偏斜 / 多峰判据用**确定性公式** | 模型目测分布、自由裁量 | 不可回归、不可复现 |
| D12 | 纯本地处理，无网络请求 | 在线取数 / 远程字体 / 埋点 | 隐私红线 + 零 CDN + 确定性 |
| D13 | 品牌隔离：本题只做"数据→图表的诚信审计" | 与本系列其他项目共用名称、素材、文档模板或交叉引用 | 领域不同，交叉引用会污染定位与检索 |
| D14 | 扩展项（更多图型 / CSV 导出 / CI 集成）不进首期 | 首期塞入扩展项 | 首期范围必须可完成、可验收 |
| D15 | M6 口径采用"Release 附产物" | 用源码 zipball 冒充产物 | 源码压缩包不是交付物 |

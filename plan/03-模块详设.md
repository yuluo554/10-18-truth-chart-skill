# plan/03 — 模块详设（M1–M5 实现级设计）

> 口径引用一律指向 `data/README.md` 第四节（行号口径 / 变换白名单 / Fraction / 舍入 / N_MIN / 偏斜多峰公式 / G1–G3 / 严重级别 / verdict / 退出码 / 几何常量 / 确定性）。

## M1 解析层 `chartaudit/parse.py`

- **CSV/TSV 判别**：按表头列数一致性实测判定分隔符（`,` 或 `\t`），歧义 → exit 2；编码仅 UTF-8（含 BOM），解码失败 → exit 2 显式报错，**不做猜测性转码**。
- **类型推断**（固定顺序）：整数 → 十进制数 → ISO 8601 日期子集 → 字符串；禁 locale（不识别千分位/本地化日期）。列类型取**全列一致**，冲突单元格记入 diagnostics（列降级为 string + 冲突计数）。
- **缺失值**：空单元格 + spec 声明的 null 标记；diagnostics 记录缺失位置与计数。
- **重复统计**：整行完全重复与声明主键后的重复键**分开统计、分别报告**。
- **规格编译**：`mark ∈ {bar, line, scatter, box}`（误差棒挂 bar/line/scatter）；`encoding` 白名单 `{x, y, series, error_bar}`；**未知字段直接报错**；分类顺序 = spec 显式序 > 首现序，禁 locale 排序。
- **输出**：`dataset.json`（含源文件 SHA-256、每列类型）、`diagnostics.json`、`chart_spec.normalized.json`（字段序固定）。
- 失败路径：空文件 / 无表头 / 列数不齐 → exit 2，零写入。

## M2 溯源层 `chartaudit/provenance.py`

- 每个渲染数值一条记录：`rendered_value_id`（SHA-256 前 16 hex）、`row_index`（0-based 数据行）、`csv_line`（冗余提示 = row_index+2）、`column`、`raw_cell`（原始字符串不规范化）、`parsed_value`、`transform_chain`（结构化白名单变换）、`sources[]`（聚合值的全部源单元格）、`exact_value`、`rendered_label`、`recomputed_value`、`match`。
- **变换白名单**：`identity / filter / group_sum / group_mean / group_median / group_count / ratio / sort / top_n / stack_offset`（口径 §2）；白名单外 → exit 2。`sort/top_n/stack_offset` 只作后处理（需参数），不能直接充当 `y.aggregate`。
- **聚合语义**：`bar/line/scatter` 无 `aggregate` 时按行 identity；有 `group_*` 时按 `(series, x)` 首现序分组；`pie` 未声明时默认 `group_sum`；`box` 以逐观测 identity 记录（白名单无分位数变换，箱线统计由 M5 从记录派生）。
- **重算**：`Fraction` 从 `raw_cell` 字符串构造（口径 §3）；百分比/均值先记精确值再按 spec 小数位 ROUND_HALF_UP（口径 §4）；比较 = 渲染标签舍入值 vs 同规则重算舍入值，要求精确相等。
- **不变量 + G1**：每个可见数值**有且仅有一条**溯源记录；重复 `rendered_value_id` → 冲突 ERROR；缺记录 / `match=false` / 行或列不存在 / `raw_cell` 不符 / 源文件 SHA-256 不符 → ERROR。验证器 `provenance.validate` 的 gate_id 与 verdict 语义在 M4 直接复用，不写第二份判定。
- 输出：`provenance.json` + 源文件 SHA-256 / 行数 / 列名表；CLI 在 `verdict=blocked` 时返回 1 并置 `render_allowed=false`（M5 渲染器据此阻断）。

## M4 窄缝门禁 `chartaudit/gates.py`（差异化主线）

- **G1 溯源完备性**：缺记录 / `match=false` / 行列不存在 / `raw_cell` 与源不符 / SHA-256 不符 → 各 ERROR（口径 §12）。
- **G2 样本量门禁**：`n < N_MIN` 且（偏斜 或 多峰）→ ERROR；`undetermined` → WARN（报告注明"未判定"）；合规替代（散点叠加或箱线）→ 降级 INFO（口径 §9）。偏斜/多峰按口径 §7/§8 确定性公式，**禁止模型目测**。
- **G3 误差棒来源真实性**：`sd/sem/ci/n` 四种声明按口径 §11 判定；列名匹配走 `references/aliases.json` 别名表（大小写规则一处定义）；"只写在标题的自由文本声明"无数据来源 → ERROR；未声明但有可疑列 → INFO。
- 输出：`gates.json`（逐项判定 + 证据 + `verdict`）。`verdict=blocked` ⟺ 有 ERROR（口径 §14）。
- 阈值/公式/别名全部来自配置，**一处定义**；门禁不读网络、不调模型。

## M5 渲染层 `chartaudit/render.py` + `SKILL.md`

- 单文件 HTML：内联 SVG + CSS + 少量内联 JS；**零 CDN**（静态扫描门：无 `<script src>`、`<link href>`、`url()`、`@import`、`http(s)://` 资源）。
- 确定性布局：全部几何常量来自 `references/geometry.json`（口径 §16）；禁随机抖动/自适应。
- hover/focus 提示："此值来自第 `row_index+2` 行第 Y 列" + `raw_cell` + 变换链摘要（口径 §1）。
- 审计区块：ERROR/WARN/INFO 列表与计数；有 ERROR → 阻断横幅。
- 发布门：无 ERROR → 写 `dist/<name>.html` exit 0；有 ERROR → 默认不写，仅显式 `--emit-audit-html` 时写 `dist/<name>.audit.html`，exit 仍非 0（D10）。
- `SKILL.md`：触发条件 / 工作流 / 调用示例 + **机器可解析契约块**（输出字段集合、顺序、退出码语义）——与代码常量做集合相等 + 顺序相等三方断言。

# plan/02 — 架构与技术选型

> 依据 `plan/01-题目文档.md`（定稿）与 `plan/00-README总览.md`（D1–D15 决策）。
> 数值口径唯一出处：`data/README.md` 第四节；本文只引用不复写。

## 一、交付形态（D5：唯一形态）

**Agent Skill**（`SKILL.md` 主入口 + `scripts/` 确定性 CLI + `references/` 规则配置 + `data/` 合成数据与真值 + `tests/`）。
不做 GUI / 桌面 exe / 在线服务 / Vega-Lite 兼容层（D5/D6）。

## 二、技术选型

| 项 | 选型 | 理由 / 决策号 |
| --- | --- | --- |
| 语言 | Python **≥3.12**（v0.1.1 起抬 floor，理由见 D32；M1–M6 期间为 ≥3.8），**纯标准库**（`csv` / `json` / `hashlib` / `fractions` / `math` / `unittest` 或 pytest 仅为 dev 依赖） | 零第三方运行时依赖 → 干净环境与 CI 首跑风险最小；纯本地无网络（D12） |
| 精确算术 | `fractions.Fraction`（按字符串构造，禁止 float 中转） | D9、口径 §3 |
| 哈希 | `hashlib.sha256`（`rendered_value_id` 取前 16 hex；源文件 SHA-256 全长） | M2 要求 |
| 渲染 | 自研内联 SVG 生成器（字符串模板拼装，属性顺序固定） | D7/D8 |
| 交互 | 内联少量 JS（hover 溯源提示），零外部资源 | D7、零 CDN 门 |
| 测试 | pytest（dev extra）；CI 矩阵 `{ubuntu-latest, windows-latest} × {3.12}`（v0.1.1 起收敛，见 D32） | 本机双通道实测可用 |
| 打包 | 不发布 PyPI；仓库即交付物，Release 附产物 | D15、题面 §四 |

## 三、分层架构（模块 = 里程碑）

```
CSV/TSV + spec.json
   │
   ▼
M1 解析层（chartaudit.parse）          → dataset.json / diagnostics.json / chart_spec.normalized.json
   ▼
M2 溯源层（chartaudit.provenance）      → provenance.json
   ▼
M3 规则门禁（chartaudit.rules）         → audit.json          ← 对齐已有工作，非创新
   ▼
M4 窄缝门禁（chartaudit.gates）         → gates.json          ← G1/G2/G3（差异化主线）
   ▼
M5 渲染层（chartaudit.render）          → dist/<name>.html    ← ERROR 时默认不写（D10）
                                                               ← --emit-audit-html 时写 <name>.audit.html 调试件（M5 已接线，K27）
```

- 每层为**纯函数**：同输入同输出、无网络、无时钟、无随机、无 locale。
- 层间产物 JSON 全部落盘（`--out-dir` 可单步复查）。
- 门禁语义：`verdict = blocked` ⟺ 存在 ≥1 `ERROR`（口径 §14）。

## 五、CLI 契约

- 入口：`chartaudit build <csv> <spec.json> --out <dir>`（交付态入口，基准打在此处；M5 起带发布门：无 ERROR → `--out/dist/<name>.html`，有 ERROR → 默认零可发布 HTML，`--emit-audit-html` 只写审计调试件）。
- 辅助子命令：`check`（只跑审计不渲染，永不写 HTML）、`selftest`（门禁自检）。
- **退出码（口径 §15，唯一语义，锁进测试）**：
  - `0` 审计通过且产物写出；`1` 存在 ERROR（阻断，默认无可发布 HTML）；`2` 用法/输入/规格错误；`3` 规则包/配置缺失或校验失败。
- 配置缺失**不得**静默按零规则通过（exit 3）；未知 spec 字段报错不静默忽略（M1）。

## 六、确定性纪律（跨模块）

1. 输出 JSON：`json.dumps(sort_keys=True, ensure_ascii=False, indent=2)` + LF + 结尾换行；写盘单点模块（`serialize.py`），原子写。
2. HTML：固定几何常量（`references/geometry.json`）、SVG 属性顺序固定、数值格式化规则固定；无时间戳/随机数/绝对路径/locale。
3. 双跑逐字节一致：`dataset` / `provenance` / `audit` / `gates` / `dist/*.html` 全部配双跑断言。
4. `rendered_value_id`：SHA-256 前 16 hex，输入字段序固定（spec_id, mark_id, series, category, row_index, column, transform_chain 规范串接）。

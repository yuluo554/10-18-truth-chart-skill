## 一、介绍

### 1.1 问题：图表"看起来对"与"数据上对"是两件事

数据到图表的链路上，最常见的失真不是画错颜色，而是**数值与来源脱钩**：

- 柱子高度是脚本里另算的一个数，没人知道它对应 CSV 的哪一行；
- 均值柱只写了"平均"，样本量 n=3 且分布两极分化，均值没有解释力；
- 误差棒标了 "±SEM"，但数据表里既没有 SEM 列，也没有可重算的重复测量；
- 报告里的百分比四舍五入后与源数据对不上，读者无法复算。

这些问题在视觉上通常"查不出来"：几何比例可以完全正确，而语义仍然不可追溯。现有反误导工具多数只检查**几何与图表类型**（非零基线、双 Y 轴、饼图、3D、平滑），不回答"**这个渲染出来的数值来自哪个单元格**""**这个均值柱该不该画**""**这根误差棒凭什么存在**"。

### 1.3 三条窄缝（本题唯一押注）

1. **逐值溯源**：每个渲染数值 → 源 CSV 单元格 `(row_index, column, raw_cell, transform_chain)`。现有工具查几何比例与规格一致性，**不查"这个标签来自哪一行哪一列"**；`honest-chart` 的 read-back 校验的是"渲染值是否等于规格值"，源单元格仍不在链路上。
2. **样本量门禁**：n 过小且分布偏斜 / 多峰时，**禁止画均值柱**（必须叠加散点或改用箱线）。现有 checker 不处理样本量与均值 / 误差棒的语义。
3. **误差棒来源真实性**：声明 `sd` / `sem` / `ci` / `n` 时，必须能在数据列或原始重复测量中找到对应来源，且 n 与实际一致。现有工具只检查误差棒"画没画"。

三条窄缝之外的一切反误导检查，一律标注为**对齐已有工作**。

## 二、任务要求（首期 5 个模块）

> 首期范围严格限定为 M1–M5。扩展项见 §2.6，不算交付物。
> 每个模块的"输入 / 输出 / 确定性纪律"即验收口径，缺一不算完成。
> **数值口径一处定义**：n 阈值、偏斜 / 多峰判据、几何常量、ERROR / WARN 判定、退出码，只在 `data/README.md` 第四节定义一次；本文引用不复写。

### 模块 M1：数据契约与图表规格

- **输入**：CSV / TSV 文件 + 图表规格 JSON。
- **CSV / TSV 解析**：
  - 编码仅接受 UTF-8（含 BOM）；其他编码明确报错，不做猜测性转码；
  - 分隔符仅接受逗号与制表符，按表头列数一致性判定；歧义时报错；
  - 类型推断顺序固定：整数 → 十进制数 → ISO 8601 日期子集 → 字符串；**禁止 locale 相关解析**（不识别千分位、不识别本地化日期格式）；
  - 缺失值：空单元格与规格声明的 null 标记；诊断输出缺失单元格位置与计数；
  - 重复：整行完全重复、以及声明主键后的重复键，**分开统计并分别报告**。
- **图表规格编译**：`mark`（首期：`bar` / `line` / `scatter` / `box`，误差棒可挂在 `bar` / `line` / `scatter` 上）、`encoding`（`x` / `y` / `series` / `error_bar`）、`domain`（显式轴范围）、`annotations`。
  - 规格字段只接受白名单；未知字段直接报错，不静默忽略；
  - 分类顺序：规格显式给出的顺序优先，否则按**首次出现顺序**，禁止 locale 排序；
  - 编译输出 `chart_spec.normalized.json`，字段顺序固定。
- **输出**：`dataset.json`（解析后数据 + 每列类型 + 源文件 SHA-256）、`diagnostics.json`（缺失 / 重复 / 类型冲突）、`chart_spec.normalized.json`。
- **确定性纪律**：解析器为纯函数，同输入同输出、无网络、无系统时钟、无 locale 依赖；模型不得手工"修数据"，任何数据修正必须落为显式的 filter / transform 并进入溯源链。

### 模块 M2：逐值溯源绑定

- **输入**：`dataset.json` + `chart_spec.normalized.json`。
- **溯源记录**：每个渲染数值（柱高、折线点、散点、箱线统计量、误差棒端点）必须有一条记录：
  - `rendered_value_id`：由 `(spec_id, mark_id, series, category, row_index, column, transform_chain)` 做 SHA-256 稳定哈希（取前 16 位十六进制）；
  - `row_index`：0-based **数据行**序号（不含表头）；界面显示为"CSV 第 `row_index + 2` 行"（表头为第 1 行）；
  - `column`：源列名；
  - `raw_cell`：源单元格**原始字符串**，不做规范化；
  - `parsed_value`：按 M1 类型推断解析后的值；
  - `transform_chain`：有序变换列表；
  - `recomputed_value`：按 `transform_chain` 从 `raw_cell` 重算的结果；
  - `match`：重算结果与渲染值是否一致。
- **变换白名单**：`identity`、`filter`、`group_sum`、`group_mean`、`group_median`、`group_count`、`ratio`（显式分子 / 分母）、`sort`、`top_n`、`stack_offset`。**不允许任意代码 / 表达式 / 回调进入溯源链**；每个变换必须带参数。
- **可重算纪律**：
  - 审计基准使用 **Fraction 精确有理数**，禁止二进制浮点参与审计比对；
  - 百分比 / 均值等无限小数，先记录精确值，再按规格声明的小数位做**确定性四舍五入**；校验比较的是"渲染标签的舍入值"与"同一舍入规则下的重算值"；
  - 差异判定阈值在 `data/README.md` 一处定义；不得在代码里散落魔法数。
- **输出**：`provenance.json`——所有 `rendered_value_id` 的完整映射，附源文件 SHA-256、行数、列名表。
- **确定性纪律**：每个可见数值必须有且仅有一条溯源记录；无溯源记录的数值**不得渲染**（直接 ERROR）；同一 `rendered_value_id` 重复出现视为冲突并报错。

### 模块 M3：反误导规则门禁（**与已有工作重叠，属对齐而非创新**）

- **输入**：`dataset.json` + `chart_spec.normalized.json` + `provenance.json`。
- **规则集（首期）**：
  1. 柱状图基线非零（截断轴）；
  2. 双 Y 轴；
  3. 饼图扇区数上限与百分比求和；
  4. 3D 效果；
  5. 面积 / 半径编码（以半径或面积代替数值）；
  6. 平滑曲线过冲（曲线越过数据点极值）；
  7. 时间轴等距（把不等时间间隔画成等距刻度）；
  8. 文字 / 图元对比度；
  9. 规格合法性（未知 mark / encoding、轴范围与数据矛盾）。
- **严重级别**：`ERROR`（阻断发布）/ `WARN`（可发布但必须显示在审计报告中）/ `INFO`。级别映射在口径节一处定义，代码与文档必须一致。
- **输出**：`audit.json`——每条规则命中含 `rule_id`、`severity`、`evidence`（定位到 mark / 数值 / 规格路径）、`message`。
- **确定性纪律**：
  - 规则集是纯函数，规则执行顺序固定，输出按 `(severity, rule_id, evidence_path)` 排序；
  - **本文显式声明**：以上 9 条与 `artgas1/tufte-skill`（0★）等已有实现高度重叠，**不得作为创新点宣传**；M3 的验收只看"规则可复现、级别正确、ERROR 能阻断"，不看"规则新颖"。
- **发布门禁**：存在任一 `ERROR` → 退出码非 0，且默认不产出可发布 HTML（只允许写出带阻断标记的审计调试件，见 M5）。

### 模块 M4：三条窄缝门禁

- **输入**：`dataset.json` + `chart_spec.normalized.json` + `provenance.json` + `audit.json`。
- **G1 逐值溯源完备性**：
  - 任一渲染数值缺 `provenance` 记录 → `ERROR`；
  - 任一 `match=false`（重算不一致）→ `ERROR`；
  - 溯源记录指向不存在的行 / 列，或 `raw_cell` 与源文件不一致 → `ERROR`；
  - 源文件 SHA-256 与数据契约不一致 → `ERROR`。
- **G2 样本量门禁**：
  - 当某组 `n < N_MIN`（阈值在口径节一处定义）**且**该组分布被判为偏斜或多峰时，**禁止画均值柱**；
  - 合规替代：均值柱 + 全量散点叠加，或改用箱线图；
  - 违规 → `ERROR`；无法判定分布（如非数值列、全缺失）→ `WARN`，并在审计报告中注明"未判定"；
  - 偏斜 / 多峰判据必须是**确定性公式**（定义在口径节），不允许模型目测或自由裁量。
- **G3 误差棒来源真实性**：
  - 声明 `sd`：必须存在配对的 SD 列，或存在可重算的原始重复测量（重复行数 = n）；
  - 声明 `sem`：必须存在 SEM 列，或由 SD 列与 n 重算一致（`sem = sd / sqrt(n)`）；
  - 声明 `ci`：必须存在 CI 上下限列，或声明置信水平 + 计算方法 + n 且可重算；**不得由 SD 列直接冒充 CI**；
  - 声明 `n`：必须与实际分组计数一致（有原始重复测量时以原始行数为准）；
  - 误差棒类型只出现在标题 / 图注 / 自由文本，数据列中无对应来源 → `ERROR`（来源真实性不成立）；
  - 声明的类型与列名 / 数值不一致（如标 `sem` 但列内容与 `sd / sqrt(n)` 不符）→ `ERROR`；
  - 未声明误差棒但存在可疑的 SD / SEM 列 → `INFO`，不阻断。
- **输出**：`gates.json`——G1 / G2 / G3 的逐项判定、证据与最终 `verdict`（`pass` / `blocked`）。
- **确定性纪律**：三条门禁的阈值、公式、列名匹配规则（大小写与别名表）全部来自配置，**一处定义**；门禁不得读取网络、不得调用模型；`verdict=blocked` 当且仅当存在 `ERROR`。

### 模块 M5：单文件 HTML 渲染 + 真值基准

- **输入**：M1–M4 全部产物。
- **输出**：
  - 单文件 HTML：内联 SVG、内联 CSS、内联 JS；**零 CDN**（不允许 `<script src>`、`<link href>`、远程字体、远程图片、任何 `http(s)://` 资源引用）；
  - 确定性布局：viewBox 宽高、绘图区边距、柱宽、柱间距、标签偏移、字号、刻度数量全部由固定几何常量计算；**禁止**随机抖动、力导向、按容器尺寸自适应改变几何；
  - hover / focus 提示："此值来自第 X 行第 Y 列"（X / Y 按 M2 的显示口径），并显示 `raw_cell` 与变换链摘要；
  - 审计报告区块：`ERROR` / `WARN` / `INFO` 列表与计数；存在 `ERROR` 时页面显示阻断横幅。
- **发布门禁**：
  - 无 `ERROR`：写出 `dist/<name>.html`，退出码 0；
  - 有 `ERROR`：默认**不写** `dist/<name>.html`；仅当显式指定调试开关时写出 `dist/<name>.audit.html`（带阻断标记），退出码仍为非 0。**不得用"生成成功"掩盖审计失败。**
- **真值基准**：
  - 合成数据表 + 植入真值台账：预先登记"哪张图应被判 `ERROR`、命中哪条规则""哪个渲染值应溯源到哪个 `(row_index, column)`"；
  - 基准必须打在**交付态入口**（`chartaudit build` 全链），不能只测内部函数；
  - 真值由生成脚本程序化产出并冻结，禁止手抄回填；
  - 至少覆盖：干净图通过、M3 每类违规各一例、G1/G2/G3 每类违规各一例、误差棒四种声明各一例、溯源到具体单元格的正例。
- **确定性纪律**：同一输入连续渲染两次，HTML 字节级一致（时间戳、随机数、哈希种子全部禁用或固定）；SVG 属性顺序固定；数值格式化规则固定。

## 八、边界与非目标

- **不追求视觉美观**：不与该赛道比审美；HTML 的目标是"可读 + 可审计 + 确定性"，不是出版级设计。
- **不做图表类型推荐引擎**：模型只给建议文本，不产坐标、不产数值、不改变图表结构；所有几何与数值来自确定性引擎。
- **不做数据抓取**：只读用户本地 CSV / TSV；无网络请求；无爬虫。
- **不做统计分析推断**：不跑显著性检验、不做回归、不做预测；G2 只做"是否允许画均值柱"的展示门禁，不输出统计结论。
- **不做通用 spec 兼容层**：不解析 Vega-Lite / Plotly / ECharts 配置（已有工具覆盖）。
- **隐私红线**：数据纯本地处理，不上传；HTML 不嵌外链、不回传埋点。
- **品牌隔离**：本题是"数据→图表的诚信审计"；文档、仓库名、Skill 名不引用本系列其他项目的名称、素材或文档模板。
- **首期范围限定**：只承诺 M1–M5；§2.6 扩展项不算交付物。
- **不编造**：不写无法核对的文号、数值、日期；检索计数与星数一律与基准日 2026-10-17 成对出现。
- **风险如实登记**：若开发时放弃任一窄缝，本题将退化为对已有 checker 的重复实现（见 §九）。
